# beFair.Ai Web App

## Getting started

Clone the repo locally using git clone https://gitlab.com/befairai/befair.ai-web-app.git

Ensure you have NodeJS installed on your local machine along with npm.

Then run the following commands:
```bash
npm install
npm run build
npm run preview
```

## What is beFair.ai?
beFair.Ai is a simple DRS (Dispute Resolution System) platform with an Ai judge.

### Components
We use the following tech stack
- Firebase backend
- Google Cloud Functions
- OpenAI GPT-4o for Ai features
